### 🔄 Güncellemeler yeniden geliyor

- **Windows'ta otomatik güncelleme düzeldi.** GitHub deposunun adı küçük harfle `umd-plus` olduktan sonra kurulu kopyalar yeni sürümü "bu projenin yayınlarından değil" diyerek reddediyordu. Uygulama artık deponun adını büyük-küçük harfe bakmadan tanıyor. 3.3.2 ve öncesinde güncelleme gelmediyse bu sürümü bir kez elle kur; sonrakiler yine kendiliğinden gelir.
- **Her sürümün kendi yayın sayfası var.** Sürümler artık tek bir sayfanın üzerine yazılmıyor; her biri kendi notları ve dosyalarıyla ayrı yayınlanıyor. 2.5.1'den bu yana bütün sürümler de kendi sayfalarına kavuştu. Uygulama güncellemeyi en son sürümün sayfasından alıyor.

### ✨ Daha akıcı geçişler

- **Sekmeler yana kayıyor.** Düzenle ile Dönüştür ve Sürüyor, Geçmiş ile Abonelikler arasında geçerken sayfa artık aşağıdan yukarı gelmiyor: sağdaki sekmeye geçince içerik sağdan, soldakine geçince soldan geliyor.
- **Kenar çubuğundaki seçim yeniden kayıyor.** Sayfalar arasında geçerken seçili satırın kutusu bir öncekinden yenisine süzülüyor; bir önceki sürümde bu animasyon kaybolmuştu.

## English

### 🔄 Updates arrive again

- **Automatic updates work again on Windows.** Once the GitHub repository was renamed `umd-plus` in lower case, installed copies refused every new version as "not from this project's releases". The app now recognises the repository's name in any case. If 3.3.2 or older never updated, install this version once by hand; later ones arrive on their own again.
- **Every version has its own release page.** Versions are no longer written over one page; each is published with its own notes and files, and every version since 2.5.1 now has its page too. The app takes its updates from the latest version's page.

### ✨ Smoother movement

- **Tabs slide sideways.** Between Edit and Convert, and Running, History and Subscriptions, the page no longer rises from below: a tab on the right comes in from the right, and one on the left from the left.
- **The sidebar's selection glides again.** Moving between pages, the selected row's box slides from the old one to the new; the last version had lost that movement.
